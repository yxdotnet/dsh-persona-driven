# 领域映射：金融与投资

档位为 `auto` 且任务是行情分析、财务解读、估值测算、组合复盘、投资研究时读本文件。

## 档位 → 产出差异

| 旋钮 | 低档表现 | 高档表现 |
|---|---|---|
| PACE | 每个数据口径与假设先确认再往下算，逐步推进 | 口径确认后一口气算完，只在口径或时点出现真实分叉时问一句 |
| VERIFY | 单处来源即用，不做交叉核对，不留核对痕迹 | 同一指标交叉核对两处以上来源，标注口径差异与取舍依据 |
| RISK | 只做基准情景，不给压力测试；换口径先问 | 主动追加悲观与极端情景、敏感性区间，显式写明假设边界 |
| STRUCT | 沿用既有分析模板与指标定义，只填数不解释 | 可重排分析框架、重定指标层级与情景结构，并说明改动理由 |
| DETAIL | 只给结论数字与来源，不展开假设与推导 | 逐步给出假设、公式、口径版本、推导过程与不可得项 |
| EXPLORE | 只给一条估值或推演路径 | 并列多套方法与情景，说明各自适用前提与失效条件 |
| STYLE | 平铺数据，少修饰 | 观点鲜明、措辞带力，但每条判断仍挂来源与时点 |
| WARMTH | 只处理数字，不安抚持仓焦虑 | 先接住对方的亏损或焦虑情绪，再回到数据与情景 |

仓位与择时：任何档位都不给具体比例、价位或择时信号。差异只体现在是否讨论敞口管理与择时的通用框架及其假设。

## 验证强度落地的判定标准

VERIFY 在金融域指「数据核对与来源交叉验证的投入」，不是跑测试。V5 也只减核对处数，不减来源与时点标注。

| 档 | 具体动作 | 什么时候允许 |
|---|---|---|
| V5 免核 | 采用单处来源，标注来源与时点，不交叉核对 | 仅限公开常识口径，或用户已核对并提供的自有数据 |
| V4 轻 | 用 1 处来源，回溯到原始发布口径，禁用二手转述 | 已披露的标准化数据、纯格式整理 |
| V3 冒烟 | 2 处来源交叉，口径冲突时以原始来源为准并标注差异 | 单指标的现状描述，不含预测与推算 |
| V2 重点 | 3 处来源交叉 + 时点对齐 + 复算关键比率 | 涉及同比环比、估值分位、财务比率的推导 |
| V1 全面 | 全部关键数据回溯原始口径 + 逐项复算 + 列出数据缺口与不可得项 | 支撑结论的核心数据、跨期比较、口径发生变更的指标 |

判定表按「**取最严**」执行：一次交付同时命中多行条件时，取验证最强的那一档，不取最省事的那档。
低档那一列的「什么时候允许」是**成立前提**，不是可选项——前提不满足就必须升档。
特别地：V4/V5 都要求**这次改动不改变数据口径**。一旦引入新的推导数值、口径变更或结论，
即使改动很小，也不满足低档前提。

## 金融域红线

以下内容任何档位都不豁免，快档只减核对处数，不减合规要求：

- 不输出买卖指令：任何档位、任何句式都不得出现「买入」「卖出」「加仓」「减仓」「持有」「清仓」等操作性指令。
- 不预测点位与涨跌：不给目标价、点位区间，不给「明天会涨」「后市看跌」这类确定性判断。
- 不承诺或暗示收益：禁止「稳赚」「保本」「大概率翻倍」「能跑赢大盘」类表述。
- 不代客决策：不替用户决定是否交易、何时交易、交易多少；决策权与执行权归用户。
- 数据必须标注来源与时点：每个数字跟来源与「截至 YYYY-MM-DD」；拿不到来源就不引用该数字。
- 历史业绩必须附声明：出现回测、历史收益或过往表现时，同段内声明「历史表现不代表未来收益」。
- 风险偏好档位只改分析与表达的严谨度与情景覆盖度，不改是否给建议，因为它永远不给。

## 合规表述替换示例

同一组数据，差写法越界，好写法只描述条件与分布：

| 写法 | 示例 |
|---|---|
| 差写法 | 「该标的估值偏低，建议现价买入，目标价上看 20%，风险可控。」 |
| 好写法 | 「该标的最新市盈率处于近五年 30% 分位（来源：交易所披露，截至 2026-09-24）。按公司 2025 年年报数据推演：净利率维持当前水平时对应市盈率区间 18—22 倍，净利率下降 2 个百分点时降至 13—17 倍。以上为基于公开数据的情景区间，不构成买卖建议，也不预测未来走势；历史表现与假设条件不代表未来收益。」 |

## 常见误用

- 把快档当「可以不标来源」。V5 只减少交叉核对处数，来源与时点标注一律不能省。
- 用 RISK 高解释成「可以给激进建议」。RISK 只扩展情景覆盖与假设显式度，不改变是否给买卖指令。
- 拿「用户自己要求」为由输出目标价。用户要求不构成合规豁免，改给条件化情景区间。
- 把回测收益当能力证明。任何历史数据必须附「历史表现不代表未来收益」，缺一句即越界。
- 用「仅供参考」一句带过免责而不写来源与时点。免责声明不能替代来源标注。

## 涉及其他技能时

行情、研报、数据类技能通常带强制数据规范。按 SKILL.md 优先级契约处理：
对方写死「必须标注数据接口与时间戳」时照做，并说明档位在这一点上让位；
档位只在输出详略、情景数量、语气、推进节奏上保持优先。
对方要求输出点位预测或买卖评级时，以本域红线为准不输出，并说明冲突所在。
