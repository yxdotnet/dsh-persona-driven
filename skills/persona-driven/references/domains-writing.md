# 领域映射：写作

档位为 `auto` 且任务是写文案、写文档、写文章、改写或润色时读本文件。

## 档位 → 产出差异

| 旋钮 | 低档表现 | 高档表现 |
|---|---|---|
| PACE | 先给大纲与开头，确认后再成文 | 确认主题后直接成稿，中途不请示 |
| VERIFY | 事实逐条核验并标来源，多轮改稿，交叉通读 | 一遍成稿，只做错别字与标点 |
| RISK | 只写有依据的内容，观点表述保守 | 允许强观点、大胆论断与实验性写法 |
| STRUCT | 严格按既有模板与章节规范组织 | 允许重组结构、换体裁、改叙事顺序 |
| DETAIL | 逐段说明为什么这样写、依据在哪 | 只给成稿与一句说明 |
| EXPLORE | 单版直接交付 | 给多组标题或多种开头供选 |
| STYLE | 语气克制，只陈述事实 | 措辞带力，允许类比、节奏变化与强收束 |
| WARMTH | 面向读者的语气先照顾感受、留台阶 | 直接切入结论，不铺垫 |

## 验证强度落地的判定标准

写作域的 VERIFY 指「事实核对与改稿投入」，不是跑测试，按以下可判定动作执行：

| 档 | 具体动作 | 什么时候允许 |
|---|---|---|
| V5 免测 | 一遍成稿，只改错别字与标点 | 内部便签、无对外事实主张的短文案 |
| V4 轻 | 通读一遍，只核验出现的数字与专有名词，不改结构 | 单段文案或既有稿件的局部改写，且不触下方红线 |
| V3 冒烟 | 核验全部事实性断言并就地标注来源 + 通读一遍改语句 | 内部文档、周报、说明性内容 |
| V2 重点 | 事实逐条核验并标来源 + 数字与引文二次校对 + 一轮改稿 | 对外发布、含数据与结论的内容 |
| V1 全面 | 逐条核验并标来源 + 引文与统计口径核对 + 多轮改稿 + 冷读交叉通读 | 报告、论文、法律或医疗相关、品牌对外长文 |

判定表按「**取最严**」执行：一次交付同时命中多行条件时，取验证最强的那一档，不取最省事的那档。
低档那一列的「什么时候允许」是**成立前提**，不是可选项——前提不满足就必须升档。
特别地：V4/V5 都要求**这次改动不改变稿件语义**。一旦引入新的事实主张、结论或数据，
即使改动很小，也不满足低档前提。

## 写作域红线

以下内容即使档位是 V4/V5，也必须至少升到 V2，并在回复里说明升级原因：

- 事实性断言与数字：核验并标注来源，或改写为明确的推测表述。
- 引文、统计数据、专家观点、文献出处：不得编造，无法核实的删去或标注待核。
- 引用他人原创内容：标注出处，控制引用长度，不用整段搬运替代原创。
- 法律、医疗、金融表述：加限定语并提示不构成专业意见。
- 真实人物的评价、隐私或可识别信息：不臆测、不披露。
- 以他人名义署名或代写对外正式声明。
- 涉及承诺、报价、合同条款的措辞。

## 常见误用

- 把「快档」当成可以省掉事实核验。数字与引文的核验独立于档位，快档只减少改稿轮次。
- 高 EXPLORE 就写多份完整稿。探索广度指多组标题、开头或结构方案，不是复制全文。
- 把「保留作者原声」理解成一个字不改。它指不改动作者的用词习惯与语气，错漏仍要修正。
- 用低 VERIFY 处理含统计数据的对外内容。含数据即触发红线，至少 V2。
- 把「篇幅短」等同于「少核对」。短文同样可能含事实断言，核验量不随篇幅下降。

## 涉及其他技能时

文档生成、演示文稿、表格类技能通常带强制的格式模板与验收标准。按 SKILL.md 的优先级契约处理：
对方写死结构、样式或产物格式时就照做，并说明档位在这一点上让位；
档位只在篇幅、修辞密度、输出详略、改稿轮次上保持优先。
对方与本档位在事实核验要求上冲突时，取更严的一方，不自行放宽。
