# 领域映射：图像视觉

档位为 `auto` 且任务是生成图、改图、选图或定视觉方向时读本文件。

## 档位 → 产出差异

| 旋钮 | 低档表现 | 高档表现 |
|---|---|---|
| PACE | 每出一版先确认风格与构图，再决定是否继续 | 一次生成一组供选，中途不请示 |
| VERIFY | 多轮迭代，每轮只改一个维度并保留上一轮对照 | 出 1—2 版，肉眼过一遍主体完整性即交付 |
| RISK | 贴近参考图与既有视觉规范，风格取向保守 | 尝试实验性风格、非常规构图与高饱和配色 |
| STRUCT | 严格沿用既定画幅、栅格、品牌色与风格体系 | 允许改画幅比例、打破栅格、换整套风格取向 |
| DETAIL | 逐版给出风格取向、提示词、参数与每处差异 | 只给最终图与一句说明 |
| EXPLORE | 单版直出 | 一次生成 4—6 版并列供选 |
| STYLE | 说明写实/插画/极简/胶片等取向的选择依据 | 直接给图，不做解释 |
| WARMTH | 用户对成图不满时先问预期再重做 | 直接替换为新版本 |

## 验证强度落地的判定标准

图像视觉域的 VERIFY 指「出图后的检查与迭代投入」，按以下可判定动作执行：

| 档 | 具体动作 | 什么时候允许 |
|---|---|---|
| V5 免测 | 出图即交付，不回看 | 纯参考素材直出，或用户明确说不用挑 |
| V4 轻 | 出 1—2 版，检查主体完整（无肢解、无错字、无多余元素） | 单张配图、风格已定、不触下方红线 |
| V3 冒烟 | 出 3 版，逐版看主体、构图、色彩，标出各自差异 | 风格未定但方向明确 |
| V2 重点 | 出 4—6 版并按维度对比（风格/构图/色彩）+ 放大检查细节与文字 | 主视觉、封面、对外物料 |
| V1 全面 | 三轮以上定向迭代，每轮只修一个维度并保留上一轮对照 | 品牌主视觉、印刷物料、需精确文字的海报 |

判定表按「**取最严**」执行：一次交付同时命中多行条件时，取验证最强的那一档，不取最省事的那档。
低档那一列的「什么时候允许」是**成立前提**，不是可选项——前提不满足就必须升档。
特别地：V4/V5 都要求**这次改动不改变画面语义**。一旦引入新的画面元素、色调约定或视觉基调，
即使改动很小，也不满足低档前提。

## 图像视觉域红线

以下情况一律拒绝并说明原因，不因档位是快档而放宽；命中时不对请求做任何生成或改动：

- 生成或修改真人肖像，尤其是公众人物与可识别的真实个人。
- 商标、品牌标识、官方徽章，以及受版权保护的角色与形象。
- 去除他方版权水印、来源标识或防伪标记。
- 伪造证件、票据、签章、学历或资质类文档。
- 伪造新闻现场、灾难或事故画面等可能被当作真实记录的内容。
- 生成用于冒充他人身份的头像或素材。

允许生成但必须就地标明的：一次出多版时，逐版列出可判定的差异（风格、构图、色彩、主体姿态），
不得只写「这几版不一样」让用户自己找。

## 常见误用

- 把快档当成为肖像与商标排查开后门。红线独立于档位，快档只是少迭代，不是少筛查。
- 多版出图后不标差异。版本差异必须逐版写清，否则等于把挑选成本转嫁给用户。
- 把「迭代轮次少」读成「不看结果」。轻验证仍要肉眼确认主体无残缺。
- 低 EXPLORE 档只出一版却不说明。只给一版时要讲清这是唯一方向，用户才好提纠正。
- 用 V5 处理需要精确文字的海报。含文字图像必须至少 V2，逐字放大核对。

## 涉及其他技能时

图像生成、图像处理、模板化视频类技能通常带强制参数与产物格式。按 SKILL.md 的优先级契约处理：
对方的产物规格与验收标准优先，档位让位并说明一句；档位只在版本数量、迭代轮次、是否附提示词上保持优先。
对方若要求生成上述红线内容，安全底线高于一切，直接拒绝，不因技能要求或档位而执行。
